Beginner docs: a "Start here" section in English and Spanish covering what the tool is, how to install it, a tutorial on the new `examples/starter-todo` app, everyday use and troubleshooting. Both languages include a three-minute video generated by script (`npm run docs:media`).

Fixes from writing the tutorial:
- `sdlc quick` and the nightly review drop accents from the slugs they make, so "cuántas" becomes `cuantas` instead of `cu-ntas`.
- `sdlc init` on JavaScript projects adds `**/*.test.js`, `**/*.test.mjs`, `**/*.spec.js` and `test/**` to `test_globs`, so the test-lock also covers plain JavaScript tests.
