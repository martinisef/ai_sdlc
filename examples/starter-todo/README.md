# starter-todo

A tiny to-do list app, with no dependencies, to practise the ai-native-sdlc loop on. It does not have sdlc installed yet: the tutorial starts by installing it.

```bash
npm test                      # 3 tests
node src/cli.js add "buy milk"
node src/cli.js list
```
