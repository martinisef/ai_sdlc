# Trackers

`tracker.provider` picks one: Jira, GitHub Issues or Linear (or `none`). `sdlc tracker …`, the loop skills and `sdlc ci tracker-merged` work the same with all three; failures are warnings, never a blocked step.

First time? [Connect Jira](../start/jira.md) is the step-by-step guide.
