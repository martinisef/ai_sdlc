# Trackers

`tracker.provider` elige uno: Jira, GitHub Issues o Linear (o `none`). `sdlc tracker …`, las skills del loop y `sdlc ci tracker-merged` funcionan igual con los tres; las fallas son avisos, nunca un paso bloqueado.

¿Es la primera vez? [Conectar Jira](../empezar/jira.md) es la guía paso a paso.
